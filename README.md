# ✨ RoyalMist

A modern, elegant, and fully responsive aesthetic perfume landing page built with HTML5, CSS3, and JavaScript. 

---

## 🌸 About the Project
**RoyalMist** is a clean and visually appealing e-commerce style landing page designed to showcase luxury fragrances and product rituals. It features a sleek dark/minimalist aesthetic layout tailored for a smooth user experience across all devices.

---

## 🛠️ Built With
* **HTML5** - Structure and semantic markup
* **CSS3** - Styling, Flexbox, custom variables, and layout design
* **JavaScript** - Interactive elements and dynamic behavior
* **Vercel** - Deployment and hosting
